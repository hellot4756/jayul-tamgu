# 〈화법과 언어〉 자율 탐구 보고서 웹앱 (Cloudflare 버전)

학생이 학번 + 개인 코드로 로그인해 한글 양식과 같은 보고서를 워드프로세서처럼 쓰고,
교사는 활동 지정·양식 편집·학생별 문서와 수정 이력(붙여넣기 기록 포함)을 확인하는 웹앱입니다.
서버는 Cloudflare Workers, 데이터는 Cloudflare D1(무료)에 저장됩니다. 결제 수단 등록이 필요 없습니다.

## 설치 순서 (명령어 입력 없이 웹에서만, 약 15분)

### 1. GitHub에 올리기
1. GitHub에서 새 저장소를 만듭니다(예: `jayul-tamgu`, 비공개 권장).
2. 이 폴더의 파일 전체를 저장소에 올립니다. (웹에서 [uploading an existing file]로 끌어다 놓기 가능. `node_modules` 폴더는 올리지 마세요.)

### 2. Cloudflare에 연결하기
1. https://dash.cloudflare.com 에 가입·로그인합니다(무료 플랜, 카드 불필요).
2. **Workers & Pages → Create application → GitHub** 를 고르고 방금 만든 저장소를 선택합니다.
3. 프로젝트(Worker) 이름은 **`jayul-tamgu`** 로 둡니다. (`wrangler.jsonc`의 `name`과 같아야 합니다. 다른 이름을 쓰려면 `wrangler.jsonc`의 `name`도 같이 바꾸세요.)
4. 빌드 명령은 비우고, 배포 명령은 기본값(`npx wrangler deploy`) 그대로 **Save and Deploy**.
5. 배포 중 D1 데이터베이스 4개(`DB`, `IMG0`, `IMG1`, `IMG2`)가 자동으로 만들어져 연결됩니다.

### 3. 교사 비밀번호 정하기
교사 계정은 **189반 / 234반 / 567반** 3개입니다. 교사마다 명단·학생·보고서가 따로 보이고(서로 볼 수 없음), 양식(활동 1·2)은 함께 씁니다.
Worker 화면 **Settings → Variables and Secrets → Add** 에서 아래 값들을 **Secret** 형식으로 추가하고 Deploy 합니다.

| 이름 | 값 |
|---|---|
| `TEACHER_PW_189` | 189반 교사 비밀번호(8자 이상) |
| `TEACHER_PW_234` | 234반 교사 비밀번호 |
| `TEACHER_PW_567` | 567반 교사 비밀번호 (예전에 만든 `TEACHER_PW`가 있으면 이것을 대신 써도 됩니다) |
| `TOKEN_SECRET` | 길고 무작위한 글자(40자 이상). 로그인 열쇠를 만드는 데 쓰이며 기억하지 않아도 됩니다 |

- 사용하지 않는 교사 계정은 비밀번호를 만들지 않으면 로그인할 수 없습니다.
- 학번은 교사끼리 겹치면 안 됩니다. 다른 교사 명단에 이미 있는 학번은 등록할 때 건너뜁니다.
- 교사 이름(189반 등)을 바꾸려면 `src/index.js` 맨 위의 `TEACHERS`를 고치세요(`key`는 Secret 이름 `TEACHER_PW_<key>`와 연결됩니다).
- 교사 계정 기능을 넣기 전에 등록한 학생은 모두 **567반** 소속으로 자동 이전됩니다.

### 4. 처음 사용
1. Worker 화면의 주소(`https://jayul-tamgu.<계정이름>.workers.dev`)로 접속 → **교사** 탭 → 교사(189반/234반/567반)를 고르고 비밀번호로 로그인.
2. **명단·개인 코드** 탭에서 학번과 별칭(실명 대신)을 엑셀에서 복사해 붙여넣고 [등록하고 개인 코드 만들기].
   [CSV 내려받기]로 코드표를 받아 학생에게 본인 줄만 알려 주세요.
3. **학생 현황·활동 지정** 탭에서 학생별(또는 반별 일괄) 활동 1/2를 지정합니다.
4. **활동 1·2 양식 편집** 탭에서 양식을 고칠 수 있습니다. (이미 쓰기 시작한 학생에게는 반영되지 않습니다.)

## 코드를 고치고 싶을 때
GitHub 저장소의 파일을 고치면(`main` 브랜치에 저장) Cloudflare가 자동으로 다시 배포합니다.
- `src/index.js` 서버, `public/index.html` 화면, `src/templates.js` 기본 양식.

## 내 컴퓨터에서 시험하기 (선택)
```
npm install
cp .dev.vars.example .dev.vars   # 시험용 교사 비밀번호
npx wrangler dev                 # http://localhost:8787
```

## 용량·한도 (무료 플랜)
- 이미지는 학생 1인당 최대 60장, 올릴 때 가로·세로 1000px 이내로 줄여 보관합니다(1장 약 100~250KB).
  반을 3묶음으로 나누어 D1 데이터베이스 3개에 저장하므로, 200명이 10장씩(2,000장)이어도 여유가 있습니다.
- Workers 무료 플랜은 **하루 요청 10만 건**, D1은 **하루 쓰기 10만 행**까지입니다. 자동 저장은 20초 간격이라 수업 시간에 한 반(약 30명)이 쓰는 정도는 충분하고,
  200명이 같은 날 동시에 몇 시간 쓰면 한도에 가까워질 수 있으니 **반별로 시간을 나누어** 쓰기를 권합니다.
  한도를 넘으면 그날(한국 시간 오전 9시 초기화)은 저장이 막힙니다.
- 화면 파일(HTML)은 정적 파일로 제공되어 요청 한도에 들어가지 않습니다.

## 보안·개인정보 메모
- 개인 코드와 교사 비밀번호는 코드에 들어 있지 않습니다(GitHub에 올라가지 않음).
- 학생은 자기 문서·이미지만 열 수 있고(서버가 확인), 로그인 5회 실패 시 10분간 잠깁니다.
- 데이터가 해외 서버(Cloudflare)에 저장되므로, 학교의 개인정보 처리 방침과 학생·학부모 안내가 필요한지 확인하세요. 실명 대신 별칭을 쓰는 것을 권장합니다.

## 문제 해결
- 배포 시 D1 관련 오류가 나면: 대시보드 **Storage & Databases → D1** 에서 데이터베이스 4개를 직접 만든 뒤,
  `wrangler.jsonc`의 `d1_databases` 각 줄에 `"database_name"`과 `"database_id"`를 추가하고 저장하세요.
- 교사 로그인 시 “비밀번호가 아직 설정되지 않았습니다”가 나오면 3단계를 다시 확인하세요.
